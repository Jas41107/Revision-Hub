# RevisionHub

RevisionHub is a modern dark-mode learning and productivity dashboard tailored for adaptive revision, DSA prep, C programming, habits, contests, LinkedIn content planning, and analytics.

## Features

- Dashboard overview with study momentum and revision queue
- Learning tracker for weekly tasks and progress
- DSA and C programming mastery tracking
- LTPs, habits, contests, and LinkedIn task planning
- Analytics and settings screens
- Supabase-ready schema and environment file

## Getting started

1. Install dependencies:
   npm install
2. Copy environment variables:
   cp .env.example .env.local
3. Start the app:
   npm run dev
4. Open http://localhost:3000

## Scripts

- npm run dev
- npm run build
- npm run lint
- npm run test

## Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Recharts
- Supabase-ready schema
